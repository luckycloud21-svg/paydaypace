# 월급까지

월급일까지 남은 생활비와 다음 월급일을 입력하면, 오늘 써도 되는 돈을 계산해주는 앱인토스 비게임 미니앱입니다.

## 구현 범위

- 첫 설정: 생활비, 다음 월급일, 선택 고정비·남겨둘 돈
- 홈: 오늘 예산, 오늘 남은 돈, 월급일까지 남은 일수, 내일 예상 예산, 이번 주 예산
- 지출 입력: 빠른 금액 버튼, 메모, 당일 지출 수정·삭제, 저장 전 예산 변화 미리보기
- 주간 리포트: 예산을 지킨 날, 계획 대비 남김, 요일별 막대 그래프, 규칙 기반 제안
- 공유 카드: 정확한 금액 기본 숨김, 앱인토스 공유 링크 생성 및 네이티브 공유
- 로컬 저장: 네트워크·회원가입·계좌연동 없이 기기 내 데이터 유지
- 분석 이벤트: 원본 금액 대신 구간(bucket)만 기록하고, 앱인토스 SDK `eventLog`를 사용할 수 있을 때 전송

계산 로직은 첨부된 `앱인토스_월급까지_앱구현기획서_v1.0.pdf`의 100원 단위 내림, 월급일 당일 새 주기, 29~31일 말일 보정 규칙을 반영했습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 앱을 확인할 수 있습니다. 브라우저에서는 앱인토스 네이티브 공유가 실패할 경우 Web Share 또는 클립보드로 대체됩니다.

## 검증 및 번들

```bash
npm run typecheck
npm run build
npm run bundle
```

`npm run bundle`은 `dist/`를 만든 뒤 현재 앱인토스 WebView SDK 3.x CLI로 `paydaypace.ait` 이름의 번들을 생성합니다.

## 앱인토스 콘솔에서 출시 전 교체할 항목

1. `apps-in-toss.config.ts`의 `appName`을 콘솔에서 발급받은 실제 앱 ID로 변경합니다.
2. 콘솔에 앱 아이콘, 앱 이름 `월급까지`, 카테고리 `재테크`, 상세 설명과 스크린샷을 등록합니다.
3. `npm run bundle`로 번들을 만든 뒤 앱인토스 콘솔에 업로드합니다.
4. 샌드박스/QR 실기기에서 뒤로가기, 날짜 변경, 공유, 재진입을 확인한 뒤 검수를 요청합니다.

현재 SDK 3.x CLI에서는 기존 `granite.config.ts` 대신 `apps-in-toss.config.ts`와 `webBundleDir` 설정을 사용합니다.
